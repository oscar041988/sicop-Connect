# Glosario

Cada palabra del panel explicada en una frase, con un ejemplo. Los nombres van como aparecen en la app.

| Palabra | Qué quiere decir | Ejemplo |
|---|---|---|
| **Cartel** | El anuncio de una institución que quiere comprar algo. | «Compra de GPS para 40 patrullas». |
| **Número SICOP** | El número que identifica a cada cartel en SICOP. Siempre se copia completo, con los ceros. | 20261003315 |
| **SICOP** | La página del gobierno donde las instituciones publican sus compras. | De ahí sale cada cartel del panel. |
| **Institución** | Quien compra. | Ministerio de Seguridad Pública. |
| **Panel de carteles** | La lista de carteles que pueden interesar a Hermatix. | Es la primera pantalla al entrar. |
| **Prioridad** | Qué tanto se parece el cartel a lo que vende Hermatix: Alta, Media o Baja. No dice si podemos participar. | Alta: piden GPS para flotas. |
| **Candidatos** | Los carteles de prioridad Alta y Media juntos. El panel los muestra al entrar. | Para ver los de Baja, cambia «Prioridad». |
| **Familia** | El tipo de producto de Hermatix con el que se parece el cartel. | «GPS y gestión de flotas», «Cámaras corporales». |
| **Por qué aparece** | Las frases del cartel que lo hicieron aparecer, resaltadas. | «rastreo satelital de vehículos». |
| **Plazo** | El tiempo que queda para mandar la oferta. | «Cierra en 7 días o menos». |
| **Cierre** | El día y la hora en que se acaba el plazo. Después ya no se puede ofertar. | Cierre: 02/11/2026 10:00. |
| **Vencido** | Un cartel cuyo cierre ya pasó. | Sirve para mirar, ya no para ofertar. |
| **Documentos** | Los archivos del cartel bajados de SICOP: pliego, anexos, fichas. | «Ver» los abre; «Descargar» los guarda. |
| **Pliego** | El documento principal del cartel, con todo lo que piden. | Pliego de condiciones. |
| **Resumen con IA** | Un resumen del cartel hecho por una computadora. Es preliminar: hay que confirmarlo en el pliego. | «Qué piden», «Riesgos», «Recomendación preliminar». |
| **Recomendación preliminar** | Lo que sugiere el resumen: ofertar, revisar o no ofertar. La decisión la toma una persona. | «Revisar: piden un técnico en planilla». |
| **Cita** | La marca que dice de dónde salió un dato del resumen. Es un enlace. | [DOC 1 · pág. 3] = documento 1, página 3. |
| **Requisito excluyente** | Algo obligatorio: si no se cumple, la oferta queda fuera. | «Ingeniero en sistemas en planilla». |
| **Revisión** | Lo que una persona decide del cartel, con su motivo. | «Interesa», «No interesa», «Revisar requisitos». |
| **Dar seguimiento** | Avisar a todos que alguien está trabajando ese cartel. | El cartel pasa a «Seguimiento». |
| **Encargado** | La persona responsable de un cartel en seguimiento. | Encargada: Ana. |
| **Expediente** | La carpeta de trabajo del cartel: etapa, archivos y notas. | «Abrir expediente». |
| **Etapa** | En qué va la oferta: Preparando, Enviada, Ganada o Perdida. | Preparando. |
| **Nota** | Un mensaje corto que queda guardado en el expediente. No se borra. | «Llamé a la institución, responden el lunes». |
| **Competencia** | Quién ganó concursos parecidos y por cuánto. | «Quién gana». |
| **Adjudicado** | Cuando la institución ya eligió al ganador. | «Adjudicado en firme». |
| **Correo diario** | El correo de las 8:00 con los carteles nuevos o que cambiaron. | Llega a la lista de destinatarios. |
