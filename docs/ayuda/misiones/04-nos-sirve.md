# ¿Cómo sé si un cartel nos sirve?

**Para qué sirve:** para decidir rápido si vale la pena preparar una oferta.

**Antes de empezar:** necesitas tener abierto un cartel. Haz clic en su título en el «Panel de carteles».

1. Mira la etiqueta de color arriba del título: Alta o Media.
   [captura: Cartel · resaltar la etiqueta de prioridad]
2. Lee el nombre al lado. Dice qué producto de Hermatix se parece.
   [captura: Cartel · resaltar la familia]
3. Mira el cuadro del plazo. Dice cuánto tiempo queda para ofertar.
   [captura: Cartel · resaltar el cuadro del plazo]
4. Baja hasta «Por qué aparece».
   [captura: Cartel · resaltar «Por qué aparece»]
5. Lee la «Evidencia». Son las palabras del cartel que lo hicieron aparecer.
6. Baja hasta «Líneas». Ahí está lo que compran, una cosa por fila.
   [captura: Cartel · resaltar «Líneas»]
7. Sube y lee el «Resumen ejecutivo», si ya está listo.

La prioridad dice qué tanto se parece a lo que vendemos. No dice si podemos participar: eso lo dice el pliego.

## ¿Y si…?

**¿Y si la evidencia no tiene nada que ver con Hermatix?**
Puede pasar. Marca el cartel como «No interesa» y elige el motivo «No encaja con el portafolio».

**¿Y si no hay «Resumen ejecutivo» todavía?**
Se prepara solo cada mañana, después de las 10:00. Vuelve más tarde.

**¿Y si dice «Sin líneas importadas para este cartel.»?**
SICOP no mandó las líneas. Revisa los documentos del cartel.
